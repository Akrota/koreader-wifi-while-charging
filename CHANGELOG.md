# Changelog – Wi-Fi while charging

*Deutsche Fassung weiter unten.*

## 0.1.0 (Oct 2026)

- KOReader turns Wi-Fi off when hardly any data flows for a few minutes ("Disable Wi-Fi connection when inactive"). This plugin prevents that while the device is plugged in.
- Three levels (Network → "Wi-Fi while charging"): **Off**, **Keep Wi-Fi on** (default, never turns Wi-Fi on by itself), **Keep Wi-Fi on and turn it on when plugged in**.
- Wi-Fi is never switched on if you turned it off by hand or airplane mode (AirPlaneMode plugin) is on.
- The device does not fall asleep by itself while plugged in; closing the cover and the power button still work.

# Deutsch

## 0.1.0 (Okt. 2026)

- KOReader schaltet das WLAN ab, wenn ein paar Minuten kaum Daten fließen („WLAN-Verbindung bei Inaktivität trennen“). Dieses Plugin verhindert das, solange das Gerät am Ladekabel hängt.
- Drei Stufen (Netzwerk → „WLAN beim Laden“): **Aus**, **WLAN anlassen** (Standard, schaltet das WLAN nie von selbst ein), **WLAN anlassen und beim Einstecken einschalten**.
- Das WLAN wird nie eingeschaltet, wenn du es von Hand ausgeschaltet hast oder der Flugmodus (AirPlaneMode-Plugin) an ist.
- Das Gerät schläft am Kabel nicht von selbst ein; Abdeckung zuklappen und Ein-Knopf funktionieren weiter.
